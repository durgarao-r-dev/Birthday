# Birthday Surprise — GitHub Pages Version

This is the static HTML, CSS and JavaScript version of the Birthday Surprise website. It does not require PHP, XAMPP, a database, or a server.

## Files
- `index.html` — website structure
- `style.css` — design and responsive styles
- `script.js` — scenes, music, letter sync, challenge, gift animation
- All photographs and audio files are stored directly in this same folder.

## Run locally
Open `index.html` in a modern browser. For best results, use a local static server or GitHub Pages. Click **Start Birthday Surprise** to begin; browsers usually require a tap before playing audio.

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload the contents of this folder directly into the repository root (not the ZIP file and not an extra nested folder).
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for deployment and open the Pages URL shown there.

## Secret phrase
Choose **Moham pagilipodhi** from the dropdown. The other options are **Next Vachinde** and **Ade kadu amma**.

## Important privacy note
GitHub Pages is static hosting and cannot run PHP. The challenge is now checked in browser-side JavaScript, so it is a visual/puzzle gate only—not real password protection. The final photograph is included in `final-photo.jpg` and can be accessed by anyone who knows its file URL. Do not publish private or sensitive photos in a public repository. The same applies to the gallery photos and audio file.
